# 对话时间线样式

用户反馈对话页观感差。对照真机长对话截图，根因不在玻璃控件，而在时间线本身：过程信息与回复同等醒目，把正文淹没。本文记录修正后的样式约定，交互规范仍以 [Android 对话 UI 评审稿](conversation-ui-review.html) 为准，顶部栏与输入框的材质见 [聊天页玻璃控件](glass-controls.md)，本轮未改动它们。

## 层次

一轮对话的阅读重点依次是：用户消息和回复正文、需要处理的事项、已结束的过程。

- **回复正文**是页面主角：16sp、行高 26sp，不加字距。
- **已结束的过程**收为一行 `ProcessRow`：16dp 图标、灰色文字、紧贴文字的展开箭头，与正文左对齐。步骤组和折叠后的设备操作使用同一种行。
- **卡片只在有内容要看时出现**：运行中、等待处理或已展开的设备操作、代码块、权限请求、带错误信息的失败。
- **用户主动停止或排队**是一行普通状态，不用警告色。

## 真实状态

- 回合如何结束只由结束时所在的步骤组显示。较早的步骤组按自己的步骤结果显示：全部成功显示“已完成 N 个步骤”，有失败显示“失败 · N 个步骤”，结果未确认才沿用回合状态。此前回合停止后每一组都显示“已停止”，与事实不符。
- 折叠设备操作的状态保持可见：失败用错误色，结果待确认或部分完成用警示色。外观简化不隐藏这些结果。
- 图片结果折叠时仍显示预览；失败信息保留全文和“恢复到输入框”。

## 间距

列表不再使用统一的 16dp 间距，由前后两项的类型决定（`timelineGap`）：

| 位置 | 间距 |
| --- | --- |
| 过程行之间 | 0dp，行高 40dp 已留白，读作一组 |
| 过程行与其他内容之间 | 8dp |
| 用户消息之后 | 16dp |
| 其他内容之间 | 12dp |
| 新一轮的用户消息之前 | 28dp |

用户气泡左侧至少留 48dp，避免长消息贴满整屏。

## 主题

- 中文正文不使用 Material 为拉丁文设计的字距，`MobbyTypography` 统一设为 0。所有使用对话组件的 `MaterialTheme` 都传入它。
- 配色方案补齐容器色和表面色。此前未设置的字段回退到 Material 默认紫色，这是上下文气泡发紫的原因。气泡仍是原 InputChip，位置和尺寸不变，只修正颜色。
- 对话画布上的卡片统一用 `conversationCardColor()`。此前浅色卡片与白色画布同色，代码块没有边界。
- 系统栏透明，由各页面背景延伸到状态栏下方，消除状态栏与页面之间的色差。
- 代码块显示时去掉末尾空行，复制仍保留原文。
