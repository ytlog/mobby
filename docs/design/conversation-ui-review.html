1. 页面结构与会话导航

以对话为主屏：顶部切换 Agent 与管理会话，中部阅读回复和执行过程，底部输入任务。会话列表放在左侧抽屉；插件、技能和设置使用独立页面。本文定义当前目标交互，HTML 的演示范围见第 8 节。

对话主屏
├─ 菜单 → 会话抽屉 → 置顶 / 项目 / 历史 / 搜索 / 设置
├─ Agent 胶囊 → 下拉弹窗：Agent / 模型 / 思考程度
├─ 新建 → 选择 Agent 与工作区 → 空对话
├─ 更多 → 会话操作下拉菜单
├─ 执行卡 → 步骤原地展开
│  └─ 网页结果 / 放大代码 → 底部阅读面板
└─ 输入区
   ├─ 加号 → 拍照 / 照片 / 本地文件 / 插件 / 技能 / 联网搜索
   │  ├─ 插件页 → 查看 / 使用
   │  └─ 技能页 → 添加 → 与moddy对话创建 / 导入技能文件 / 手动创建
   ├─ 语音 → 按住说话 → 松手发送 / 上滑取消
   └─ 发送 / 停止

推开式导航抽屉 · Navigation Drawer

点击左上角三横杠，菜单从左侧滑入，整个对话区域（工具栏、消息、输入框）同步向右平移，保持原宽度并裁切超出屏幕的部分。抽屉宽度为 min(360dp, 可用宽度 − 56dp)，右侧保留原会话的一条可见区域；状态栏与系统导航区不参与平移。点击右侧区域、关闭按钮或系统返回时反向收起，恢复阅读位置与草稿。打开时收起输入法，背景会话不可操作。

顶端为本机身份和新建按钮，中部按置顶、项目、历史分组，底部固定搜索与设置。搜索过滤会话标题，选中项显示标题、Agent 和运行状态。点击会话恢复各自的草稿、附件与阅读位置；切换会话不停止任务，也不逐次堆叠返回历史。

首次进入显示空对话，后续恢复最近访问的对话。新建时选择 Agent 与可访问的工作区，发送首条任务前允许调整。已有会话通过 CLI session ID 延续上下文；恢复失败时提示重试或新建，不静默丢失上下文。

项目同时提供新对话的默认工作区和会话分组。已有对话“添加到项目”只改变分组，保留该会话的执行目录；移除分组不删除工作区。侧栏设置包含网关、运行环境、外观与已归档会话。

2. 对话内容与执行状态

每轮按“用户消息 → 公开进度与工具步骤 → 最终回复 → 产物”排列。用户消息为右侧气泡，回复直接排版，过程收在细边框卡片中。仅展示 Agent 已提供的公开进度和工具结果。

原地展开与阅读面板

内容打开方式高度与滚动
普通步骤、工具输出点击步骤行，在同一卡片内展开；再次点击收起正文自然高度，上限 240dp；超出后正文内部滚动，步骤标题保留
网页结果、来源集合、主动放大的代码从底部打开阅读面板自然高度，上限为可用屏幕高度减 48dp；长内容接近满屏，标题固定、正文滚动
最终回复、错误摘要、待确认事项保留在时间线中随对话滚动，不随过程自动收起

高度上限按安全区与输入法占用后的空间计算；短内容不强行撑满。普通步骤变长仍在原处滚动，不突然切换成弹窗。代码支持复制、换行与放大，复制保留原始文本；来源显示可解析的标题、域名或本地路径。

折叠规则

事件默认行为用户选择
新轮次开始过程组展开，当前步骤显示摘要每轮独立记录展开状态
整轮确认成功最终回复就绪后，过程组收为状态摘要手动展开保持展开；手动收起保持收起
失败、超时、停止、中断过程保留，组外显示结果摘要允许收起过程，异常仍可见
等待权限或用户回答待处理卡片放在过程组外关闭详情不等于批准或拒绝
切换会话或旋转屏幕恢复展开选择与阅读位置不因刷新重置

用户正在阅读过程、选择文字或焦点位于详情内时，延迟自动折叠。展开与折叠保持当前可见消息的锚点；新输出仅在用户已位于底部时跟随，上滑后显示“最新消息”入口。步骤展开状态与运行状态分别保存。

执行、停止与重试

首版全局只运行一个任务。其他会话可阅读与编辑草稿，发送区提示当前占用任务。运行中改写输入框只保存下一轮草稿，不注入当前执行。

停止先显示“停止中”，收到进程终止确认后才显示“已停止”；无法确认时显示状态待核实。成功、失败、超时、中断依据真实事件与退出状态区分。重试创建新轮次，保留原结果和已产生的文件变化。权限操作必须通过真实请求 ID 回传，执行能力未接通时明确显示不可用。

3. 顶部配置与更多菜单

Agent / 模型 / 思考程度

点击顶部 Agent 胶囊，在按钮下沿展开圆角下拉弹窗，同一弹窗内依次选择 Agent、对应模型和思考程度。选中项有明确标记；选择暂存，点击应用才生效，点击遮罩或返回取消暂选。

切换 Agent 更新模型列表；切换模型后仅保留该模型支持的思考等级。Agent 选项为 Codex 与 Claude Code。可选项由网关配置和实际 CLI 能力提供；顶部配置摘要显示下一轮将使用的模型与等级。

变更应用方式
同 Agent 更换模型或思考程度下一轮生效，当前运行保留启动时的配置；若 CLI 不支持会话内切换，明确提示新建
空对话更换 Agent直接更新选择，保留文字草稿
已有记录的对话更换 Agent按钮显示“新建并使用此配置”；保留原会话和任务，复制文字草稿，不自动迁移历史、附件或权限

更多菜单

菜单右对齐更多按钮，在其下方展开，顶部显示当前会话名。高度随内容变化，超出屏幕剩余空间后内部滚动。

操作行为
分享选择消息后调用系统分享，默认排除日志和配置
置顶 / 取消置顶更新会话抽屉分组
添加到项目选择项目分组，执行工作区不变
对话附件区分已发送附件与本轮草稿附件
在聊天中查找显示匹配消息并定位结果；无结果时保留查询
添加到主屏幕交给 Android 快捷方式确认界面
重命名保存非空标题，取消保留原名
归档移出正常列表，可撤销或从归档恢复
删除单独说明影响范围并确认；提供可撤销删除，不删除工作区文件

运行中的会话不能归档或删除。菜单、详情与返回操作均不停止任务。设置从会话抽屉进入。

4. 输入与底部面板

输入区固定在底部：左侧加号，中间多行文本，右侧按状态显示语音、发送或停止。输入超过 5 行后内部滚动，回车用于换行，中文组词确认不发送。收到服务接收确认后才清空已提交草稿；发送失败保留原文。

加号面板

点击加号保存草稿与选择区，收起输入法，从底部展开面板。顶部为拖动条，上排三个等宽入口“拍照 / 照片 / 本地文件”，下方为“插件 / 技能 / 联网搜索”。联网搜索右侧显示当前偏好，默认自动。面板自然高度、设可用高度上限，超出后滚动；关闭恢复输入草稿与原阅读位置。

拍照和照片进入系统采集/选择流程，本地文件使用系统文件选择器。选择后预览名称、大小、状态和移除按钮；处理中暂不可发送，失败提供重试或移除。图片、文件和联网搜索仅在当前 Agent 与网关有实际支持路径时开放；不支持时说明原因，不静默丢弃内容。

语音

点击麦克风把输入区换成「按住说话」，右侧图标变为键盘，再点键盘回到文字并打开输入法。长按麦克风或「按住说话」开始录音。应用自带识别引擎，模型不在安装包内，只在第一次按住说话时下载。下载时输入区上方显示细进度条、已下载大小和百分比；加载时进度条保持满格。松手不会发送，进度条会留到下载结束。真正开始录音后，底部显示「松手发送，上滑取消」和随音量起伏的频谱；上滑后松手则改为「松开取消」。松手把转写写入原草稿选区并发送，上滑取消则不发送。进入后台、失去音频焦点或切换会话会停止采集。权限拒绝、下载失败、转写失败或原草稿已变化时不发送，文字输入仍然可用。轻点「按住说话」不会开始录音。

草稿与配置

文字、选择区、附件、选中的插件与技能归属当前会话草稿，切换会话不串用。使用能力仅加入草稿，可移除，发送时再验证可用性。网关设置包含协议、地址、模型与密钥，保存成功与连通性检查分别呈现；密钥和真实配置保存在设备加密存储。

5. 插件与技能

插件：只查看与使用

独立插件页包含返回、标题、搜索、分类和插件卡片。仅展示应用提供的插件，卡片可查看说明与使用；不提供添加、安装或导入入口。详情说明用途、适用 Agent、访问范围和可用状态，不可用时显示原因。

技能：目录与添加

技能页包含返回、标题、右上添加、搜索、介绍卡、分类和技能列表。可查看技能说明、来源与状态，将可用技能加入本轮草稿。搜索与分类共同过滤，返回详情后保留目录位置与筛选条件。

右上“添加”在技能页上方弹出底部面板，提供“与moddy对话创建”“导入技能文件”“手动创建”。遮罩、下拉或返回仅关闭此面板，保留技能页。

入口目标流程完成条件
与moddy对话创建
使用 Skill Creator 创建 Skill		直接新建“创建技能”会话 → 输入框预填 Skill Creator 调用提示 → 补充需求并发送 → 在会话内澄清、生成与校验保存有效 SKILL.md 写入目标 Agent 可发现的技能目录，并能重新发现
导入技能文件
支持 Markdown 文件		系统选择 .md 文件 → 解析与预览 → 补全缺失信息 → 校验导入名称、触发描述与正文有效，同名冲突已处理，导入成功后更新目录
手动创建打开表单填写名称、用途和使用场景 → 预览与修改 → 校验保存形成有效技能并加入列表，不调用 Skill Creator

对话创建不会打开表单，也不覆盖当前会话。新会话沿用所选 Agent、模型及工作区，输入框预填“请用 /skill-creator 帮我创建技能，要求是：”，光标置于末尾；用户补充要求后发送。调用由 Agent 适配层映射到其支持的技能调用机制。原会话草稿、附件和任务保留；有任务占用时新会话可编辑，但发送受全局运行锁约束。

Skill Creator 输出包含 name、description frontmatter 与 Markdown 指令正文。名称使用小写字母、数字、短横线，少于 64 个字符；说明简洁、触发范围明确，辅助脚本和资源按实际需要提供。

普通 Markdown 缺少元信息时进入补全流程。读取文件只用于预览与导入，不执行其内容；同名技能不自动覆盖。生成或导入失败保留输入，取消不新增技能，校验和写入完成后才登记成功。

创建 Skill 通过现有 Agent 执行路径调用实际可用的 skill-creator，遵守权限与沙箱。全局已有任务时保留创建需求并提示任务占用；Creator 不可用时说明原因。生成过程与普通任务共用进度、停止和错误展示，保存后返回“已添加”列表。

6. Android 布局与返回

项目设计约定
手机布局320 / 360 / 412dp 单栏；正文左右 16dp，建议 16sp；触区至少 48 × 48dp；支持深浅主题与字体放大
顶部与底部工具栏占据布局空间；输入区跟随 IME 上移；统一处理状态栏、切口和系统导航 inset
导航抽屉推开式，开合 240ms；菜单与内容共用位移进度，减少动画时直接切换。列表独立滚动，搜索和设置固定底部；预测返回跟手，取消返回恢复展开态
下拉菜单锚定对应按钮，限制在可用屏幕内；内容不足自然高度，超出后滚动
底部面板顶部圆角约 28dp；开合约 220ms，减少动画设置下取消位移动画；下拉与正文滚动由嵌套滚动协调
无障碍按钮提供操作名与展开状态；打开面板转移焦点，关闭恢复入口；只播报关键状态，不逐 token 报读

返回顺序

输入法可见时先收起输入法；随后关闭最上层下拉、底部面板或导航抽屉。技能添加面板回技能页，技能/插件详情回目录，目录回加号面板，加号面板回对话。设置回原会话；对话根页交给系统返回，不停止后台执行。预测返回取消时保留原状态。

独立页面使用导航栈；同级弹窗互相替换。技能添加是目录页上的单个覆盖层。正文滚动、步骤内部滚动与面板滚动分别记录，关闭阅读面板后恢复触发消息位置。大字体、横屏和分屏下重新计算高度上限，保留可访问的关闭与返回入口。

7. 三层交互与独立 Runtime

全部交互采用 Compose，实现为独立 Gradle 模块 :interaction-ui。交互内部划分展示、业务、数据三层；Runtime 独立成子系统，通过固定接口通信。完整技术定义见 交互三层架构与 Runtime 技术设计，本节仅说明交互落地边界。

展示层 :interaction-ui（Compose / ViewModel）
               ↓ 依赖
业务层 :interaction-domain（UseCase / 领域模型 / 端口）
               ↑ 实现端口
数据层 :interaction-data（Room / Repository / 执行适配）
               ↓ 固定契约
          :runtime-api（命令 / 快照 / 事件）
               ↑ 实现
:runtime-android（Service / 客户端 / 网关 / 环境）
               ↓
:runtime-engine（状态机 / 协议 / 调度） → :runtime-api

:app 只负责宿主、对象装配与打包。
Runtime 不依赖任何 interaction 模块。

UI 只向用例提交操作，通过 UiState 更新页面；不能直接绑定 Service、创建网关存储或访问子进程。Data 将领域请求转换为 Runtime DTO，再把结构化事件投影为消息与步骤。运行生命周期由 Runtime Service 管理，关闭页面、收起面板和停止订阅都不等于取消任务。

交互职责技术边界
抽屉、展开、滚动与返回Compose 管理；推开式抽屉菜单与内容共享动画进度，内容不缩窄；不调用 Runtime
发送、停止、配置与技能创建Domain 用例管理业务规则；Data 实现端口；命令通过 runtime-api 传递，审批与取消必须有明确回执
会话与运行恢复交互数据保存草稿和消息投影；Runtime 保存执行事实，依靠 requestId 幂等和事件游标恢复；中断不自动重发
真实能力模型、思考等级与 Skill Creator 支持由 Runtime 能力接口提供；Shell 保留为内部执行与诊断能力，不进入产品 Agent 列表

执行状态与 UI 展开状态独立。完成必须有协议和进程证据；接口断开不表示完成，取消接纳不表示已停止。正文长输出按有界分段读取，进度只展示公开摘要。凭据留在设备加密存储，常规执行请求只使用配置引用。

交付顺序

  1. 定义纯 Kotlin 领域端口与 Runtime API，完成契约测试。
  2. 提取 Runtime 引擎与 Android 宿主，消除对 app/UI 的反向依赖。
  3. 落地交互三层和 Compose 页面，先接假 Runtime 验证交互，再由 app 装配真实实现。
  4. 完成真实 CLI/网关、手机交互、前后台恢复与覆盖安装数据保留验收。

Runtime API、交互领域契约和独立执行模块已建立；交互 Data/UI 仍待实施，当前应用入口仍为接入真实 Runtime 的测试控制台。版本、Gradle 依赖图、事件语义、数据所有权及迁移验收统一维护在技术文档，不在本页重复定义。

8. 原型范围与验收

当前文件为单页、离线可打开的设计原型；交互数据仅保存在页面内，刷新后重置。尚未接入 Android 原生运行层。原型展示与目标实现的边界如下。

范围HTML 可体验原生接入要求
会话与过程推开式抽屉开合、搜索、切换、草稿隔离、重命名、归档恢复、状态切换、原地折叠与阅读面板真实消息、CLI session、持久化、权限与终态事件；HTML 停止确认由演示计时器模拟
顶部配置与更多Agent、示例模型与等级联动，项目分组，当前已渲染内容查找真实模型能力、整段会话检索、系统分享/快捷方式；删除目前只预览说明
插件与技能插件只使用；技能三入口、对话创建的新会话与预填输入、示例导入、手动创建表单与预览真实文件选择与校验；新会话发送后实际调用 Skill Creator，生成结果在对话内展示；手动创建独立保存
输入与设置示例附件、语音校对、搜索偏好、深浅主题与只读网关预览相机、文件、麦克风、转写、IME、设备加密设置与网关验证

交互验收清单

  • 普通步骤点击只在卡片内展开；短内容自然撑高，长内容限高滚动；网页结果从底部打开，关闭恢复阅读位置。
  • 默认展开的过程在确认成功后收起，用户手动选择与正在阅读的位置得到保留；错误和待确认信息始终可见。
  • Agent/模型/等级依赖正确；取消暂选不生效，应用不修改当前执行；跨 Agent 新建保留原任务。
  • 插件所有层级没有添加或安装入口；技能添加提供对话创建、导入和手动创建三个选项；对话创建直接新建会话并预填调用，不经过表单，关闭底部面板保留目录状态。
  • 技能导入取消、无效文件、同名冲突、Creator 不可用或失败均不登记成功；成功后可发现并用于草稿。
  • 会话切换、屏幕旋转与进程恢复不串草稿、附件、能力或日志；没有执行证据时不自动重发任务。
  • 320dp、360dp、412dp、横屏、200% 字号与 IME 下主要操作可见；返回层级、焦点与滚动恢复正确。
  • 真 CLI 与真实网关验证发送、审批、停止、失败和恢复；模拟结果不替代设备验收。

原型已验证主要菜单、筛选、草稿隔离、展开收起、配置联动和技能示例流程。真实文件、Skill Creator、CLI、网关、系统分享及 Android 手势与无障碍仍需接入后验收。
