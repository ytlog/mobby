# 首次使用与屏幕操作引导

## 每屏只做一件事

向导使用独立步骤页，显示“第 N 步”、当前任务、简短说明和一个主要操作。上一步与主要操作固定在底部；长说明只在中间滚动，小屏幕无需翻到底部找按钮。提示消息按实际操作栏高度避让，输入页离开时收起键盘。不再把后续权限、端口、模式和已完成步骤放在同一页面，也不使用旧的折叠卡片列表。

首次使用依次进行：

1. 选择一个 Agent；API 是可选分支。选择本身不触发登录。
2. 只登录所选 Agent，调用原有官方认证弹窗；已登录或已有 API 连接时可直接继续。取消授权留在本步骤，上一步保留所选 Agent。
3. 直接进入屏幕方式选择，不另设“打开配置页面”的中间页。选择方式只改本次向导选择，点击下一步才调用原有模式切换接口。
4. 按所选屏幕方式完成后续单独步骤；已完成的系统条件自动跳过。

引导进度和所选 Agent 单独保存在 `mobby.setup-guide`，不修改账号、使用来源或聊天。未完成时继续，完成或选择稍后后不强制重开；设置中的“使用引导”可重新进入。外部会话和程序链接保持原行为。通知权限按需申请，不抢在 Agent 登录之前弹出。

## 屏幕步骤

无障碍路径按需显示“允许通知 → 开启无障碍 → 完成”；内置 ADB 路径按需显示“开启无障碍 → 允许通知 → 连接 Wi-Fi → 开启开发者模式 → 开启无线调试 → 配对 → 连接 → 完成”。无障碍用于协助完成 ADB 设置，用户也可以选择“手动设置 ADB”。MIUI 优先打开系统的“已下载的应用”列表。其他系统优先尝试 mobby 服务详情，系统拒绝该入口时打开无障碍设置。已有 root 的设备保留独立的说明和连接步骤。虚拟屏仍要求 Android 13 以上，不自动切换权限来源。

每次只挂载当前步骤的操作内容。例如，开发者模式页没有无线调试或配对按钮；配对页没有端口输入；连接失败留在连接页，不直接在下面堆输入项。品牌选择、通知回复帮助、手动端口和断开连接分别进入独立分支页，完成或返回后回到原任务。手动端口页保存时不发起连接。

进入和返回前台时重新读取通知、Wi-Fi、开发者模式、无线调试和无障碍状态。已满足的条件在向前导航时跳过；主动返回先前步骤时保留该页，点击下一步才继续，不产生自动跳回的循环。系统不能提供的标记保持未知；仅在未知的开发者/无线调试步骤提供用户明确确认的继续入口，不因此伪造连接或权限已就绪。

开发者模式按厂商提供单独的开启说明。其他系统的选择在另一页面完成，不展开七种品牌说明。系统入口仍尝试可用快捷页和标准设置页，失败时给出路径；不写任何系统开关或权限。

启用无障碍后，可点「自动配对」。mobby 在系统弹窗仍处于前台时读取六位码与当次配对端口，只通过本机回环地址完成配对。系统确认成功后，在后台使用无线调试主页的连接端口或本机服务发现建立副屏连接，再尝试返回向导。弹窗无法识别时，可保持弹窗打开并按 mobby 通知提示手动输入六位码。

只有本次真实成功后的 `adbPairingSuccess` 内存序号增长，才会进入连接步骤。通知手动配对成功后，向导回到前台时自动连接一次。后台已完成的连接不会再发起。旧身份、取消、中断、超时或重新进入页面不会代替本次成功。配对成功但连接失败时由用户决定重试或填写端口。配对码、端口和屏幕令牌不增加持久化。

完成页依据真实通知和无障碍/连接状态显示就绪，点击下一步或跳过不等同于取得系统权限。屏幕设置可以跳过，其他 Agent、Shell、API 配置、HOME、工作区、聊天和加密凭据保持原有路径。
