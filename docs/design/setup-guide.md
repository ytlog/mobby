# 首次使用与屏幕操作引导

## 首次进入

首次进入新引导时显示完整页面，按“Agent 登录 → 屏幕操作”两步推进。已有网关也会展示登录建议，不覆盖账号、来源偏好或聊天记录。登录入口按 Codex、Claude Code、Pi、OpenCode 排列，说明对应的官方账号；API 网关作为最后的替代入口。运行环境准备期间保留说明，准备完成才允许启动登录。

登录成功并刷新连接后进入屏幕引导；取消登录返回第一步，不当作完成。用户也可直接继续屏幕设置或稍后使用。进度单独保存在 `mobby.setup-guide`，未完成时下次继续；完成或选择“稍后”后不再强制出现。设置页新增“使用引导”，随时可重新打开。外部会话或程序链接继续打开指定内容。原先只在没有连接时自动弹出的登录/API 弹窗由此取代；无连接时主动新建对话仍可打开同一组登录优先选项。

第二步说明当前屏幕与虚拟屏的区别，直达屏幕配置。返回后显示当前选择与连接状态，由用户点击“开始使用”结束引导；第二步的标题返回和系统返回都回到 Agent 步骤，不会误完成引导。完成引导不等同于已取得系统权限，不伪造任何后端就绪状态。

通知权限改为在屏幕配置中按需申请，避免首次打开时抢在登录引导前弹出。普通聊天不因此获得屏幕权限；屏幕任务原有的通知与权限检查继续有效。

## 屏幕配置

保留无障碍、内置 ADB 和 root 的明确选择，不自动替用户切换后端。当前屏幕突出最少操作路径：打开 mobby 的无障碍服务并允许通知；root 页面说明仅面向已有 root 的设备。虚拟屏仍要求 Android 13 以上。

内置 ADB 使用四步卡片：通知、开发者模式、无线调试、配对。进入及返回前台时重新读取系统状态，已完成步骤收起，突出当前未完成步骤；也可以手动展开查看说明。系统不允许读取或没有提供的标记保持“未知”，不会当作已开启或已关闭。配对身份来自现有加密存储；已配对且条件就绪时把连接按钮前置，完整步骤收进可展开说明，避免翻过完成步骤或重复配对。

开发者模式按厂商与品牌选择离线说明，并允许查看其他系统：小米/Redmi/POCO、OPPO/一加/realme、vivo/iQOO、三星、荣耀、兼容 Android 的华为、Pixel/其他 Android。说明保留常见菜单名称差异和系统设置搜索路径，不假定每个版本都有相同入口。原生鸿蒙不宣称兼容此 Android 屏幕实现。

系统跳转按可用入口尝试：无线调试快捷入口 → 开发者选项 → 系统设置；无障碍服务详情 → 无障碍设置 → 系统设置；关于手机、Wi-Fi 和通知同样保留系统设置兜底。跳转失败会提示按给出的路径操作，不标记为设置成功。不写开发者选项、无线调试、无障碍或任何系统权限。

配对操作先申请必要通知权限；若相关频道被关闭，则进入实际被关闭频道的设置。随后同一次点击启动通知配对并打开系统设置。用户在系统选择“使用配对码配对设备”，保持弹窗打开，下拉通知，通过 mobby 通知输入并发送六位码。保留已在小米上验证必要的前台通知流程，不改回切换 App 填码。小米通知没有回复框时可展开 Android 通知样式说明。

用户主动开始的本次配对成功后，返回前台自动连接一次。`ScreenControlState.adbPairingSuccess` 是仅在真实配对成功后递增的内存序号；保存过身份、取消、超时、系统停止配对服务或重新进入页面都不能替代本次成功。连接开始前消耗本次自动连接意图，失败保持失败，不循环、不跨模式重试，不在重建后恢复自动连接意图。仍可手动连接或取消。

连接端口默认自动发现，手动输入收在可展开选项中；连接失败时展开并说明连接端口与配对端口不同。端口和配对码不增加持久化；原有 Keystore、配对身份、网关与原生登录密文均不迁移、不清除。
