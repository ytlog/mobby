# Travel Packing List

Generated by Codex in mobby on an Android phone for the [English demo](../../media/en/README.md). The page includes four categories, packing progress, checkboxes, and controls to add and delete items. It saves changes in the browser's localStorage.

Run with Node.js:

```sh
node server.cjs
```

Open `http://127.0.0.1:18792/` in the browser on the same device. No packages or external assets are required.
